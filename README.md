🪷 MythoTales AI

MythoTales AI is an AI-powered web application that makes mythology more engaging, accessible, and interactive. Users can enter a mythology-related topic and generate an engaging story divided into four scenes.

✨ Features

🪷 AI Mythology Story Generation – Generate stories based on any mythology topic.
🌸 Four-Scene Storytelling – Stories are presented in a simple, structured format.
🌍 Multiple Languages – Supports English, Telugu, Hindi, Tamil, Kannada, Malayalam, Bengali, and Marathi.
🧠 Interactive Quiz – Generates 5 multiple-choice questions with answers and explanations.
🎨 Simple User Interface – Clean pastel pink and purple themed design.
⚡ Fast AI Generation – Uses Gemini Flash-Lite for efficient responses.

🛠️ Technologies Used

Python
Streamlit
Google Gemini AI
Google GenAI SDK
python-dotenv
JSON

🔄 Project Workflow

User enters a mythology topic.
User selects a preferred language.
The request is processed by Gemini AI.
AI generates a structured four-scene story.
The story is displayed through the Streamlit interface.
Users can generate a mythology quiz based on their selected topic.
The quiz evaluates answers and provides explanations.

🎯 Objective

The goal of MythoTales AI is to combine Generative AI, cultural heritage, and interactive learning to help people discover and understand mythology in a simple and enjoyable way.
